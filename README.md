# PLASSO
### Ideias que ganham forma.

Um estúdio criativo que transforma ideias em objetos personalizados por meio da impressão 3D, gravação a laser e tecnologia NFC.

## 1. Sobre o projeto

A Plasso é um projeto de desenvolvimento web criado para representar um estúdio de fabricação personalizada. O objetivo do site é apresentar a identidade da marca, divulgar suas possibilidades de criação, exibir projetos e facilitar o contato de pessoas interessadas em encomendar produtos personalizados.

O desenvolvimento foi realizado com foco na criação de uma interface visualmente atrativa, organizada, intuitiva e responsiva, buscando equilibrar tecnologia e cuidado artesanal.

## 2. Objetivos do site

- Apresentar a identidade visual e os serviços da Plasso.
- Divulgar produtos personalizados.
- Apresentar as possibilidades da impressão 3D, gravação a laser e tecnologia NFC.
- Exibir projetos e referências visuais.
- Explicar as etapas de desenvolvimento de uma encomenda.
- Facilitar o contato entre o visitante e a marca.
- Proporcionar uma experiência de navegação simples e agradável.

## 3. Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento front-end.

- **HTML5:** utilizado para estruturar o conteúdo das páginas, organizar títulos, textos, imagens, formulários, links e demais elementos.
- **CSS3:** responsável pela aparência visual do site, incluindo cores, tipografia, espaçamentos, organização dos elementos, efeitos e adaptação para diferentes tamanhos de tela.
- **JavaScript:** utilizado para adicionar interatividade e comportamentos dinâmicos à interface.
- **Git e GitHub:** utilizados para versionamento, armazenamento e acompanhamento das alterações realizadas durante o desenvolvimento.
- **Google Fonts:** utilizado para disponibilizar as fontes tipográficas escolhidas para a identidade visual.

## 4. Processo de desenvolvimento

### Etapa 1 — Definição da proposta

O primeiro passo foi definir o propósito do projeto. A ideia escolhida foi desenvolver um site institucional para a Plasso, uma marca fictícia voltada à fabricação de produtos personalizados.

Foram definidos o público que o site pretende alcançar, os serviços apresentados e os principais objetivos da experiência do usuário.

### Etapa 2 — Criação da identidade visual

Após definir a proposta, foi desenvolvida a identidade visual da marca.

A escolha das cores buscou transmitir criatividade, acolhimento e personalidade, combinando tons de bordô, creme, argila e madeira.

Também foram selecionadas as fontes Fraunces para títulos e Figtree para textos, buscando estabelecer uma hierarquia visual e manter a consistência entre os elementos.

### Etapa 3 — Planejamento da estrutura

Antes da implementação, foram identificadas as principais áreas que deveriam compor o site.

A organização foi planejada para permitir que o visitante conhecesse a marca, explorasse os produtos, compreendesse o processo de encomenda e encontrasse um meio de entrar em contato.

### Etapa 4 — Desenvolvimento da estrutura HTML

Com o planejamento definido, iniciou-se a construção da estrutura das páginas utilizando HTML5.

Foram organizados os elementos de navegação, seções de apresentação, títulos, textos, imagens, cards explicativos, botões e formulários.

A estrutura HTML foi utilizada para estabelecer a hierarquia e a organização do conteúdo.

### Etapa 5 — Estilização com CSS

Depois da estruturação, foi realizada a estilização utilizando CSS3.

Nessa etapa foram aplicados:

- Cores da identidade visual.
- Famílias tipográficas.
- Espaçamentos e alinhamentos.
- Estilização de botões e cards.
- Organização das imagens.
- Efeitos de interação e transição.
- Ajustes de layout para diferentes tamanhos de tela.

O objetivo foi construir uma interface consistente, agradável e fácil de utilizar.

### Etapa 6 — Implementação de interatividade

O JavaScript foi utilizado para adicionar comportamentos à interface.

Essa etapa contempla os recursos interativos efetivamente implementados no projeto, como controles de navegação, manipulação de elementos e interações dos componentes da página.

Os recursos devem ser descritos de acordo com seu funcionamento na versão final do site.

### Etapa 7 — Organização dos recursos visuais

As imagens e demais recursos gráficos foram organizados para complementar a identidade visual e apresentar as possibilidades de fabricação da marca.

A escolha dos elementos visuais buscou demonstrar criatividade e despertar o interesse do visitante pelos produtos personalizados.

### Etapa 8 — Testes e ajustes

Após a implementação, o site deve ser verificado para identificar problemas de navegação, apresentação e funcionamento.

Entre os pontos avaliados estão:

- Funcionamento dos links e botões.
- Carregamento das imagens.
- Organização dos elementos.
- Adaptação para diferentes resoluções.
- Legibilidade dos textos.
- Contraste entre cores.
- Funcionamento dos formulários e demais interações.

### Etapa 9 — Versionamento e publicação

Durante o desenvolvimento, o Git e o GitHub foram utilizados para registrar e armazenar as alterações do projeto.

O versionamento permite acompanhar a evolução do código, manter um histórico de modificações e facilitar a continuidade do desenvolvimento.

## 6. Estrutura dos arquivos

A organização do projeto separa os arquivos responsáveis pelo conteúdo, pela aparência e pelas interações.

```text
Plasso/
├── index.html
├── produtos.html
├── projetos.html
├── como-funciona.html
├── sobre.html
├── encomenda.html
├── assets/
│   └── images/
├── css/
│   ├── style.css
│   ├── pages.css
│   └── produtos.css
└── js/
    └── main.js
```

**Responsabilidade dos principais arquivos:**

- `index.html`: estrutura da página inicial.
- `produtos.html`: apresentação dos produtos.
- `projetos.html`: exibição dos projetos e criações.
- `como-funciona.html`: explicação do processo de encomenda.
- `sobre.html`: apresentação da marca.
- `encomenda.html`: interface destinada à solicitação de encomendas.
- `assets/images/`: armazenamento dos recursos visuais.
- `css/style.css`: estilos gerais da interface.
- `css/pages.css`: estilos complementares das páginas.
- `css/produtos.css`: estilos específicos da área de produtos.
- `js/main.js`: comportamentos e interações implementados com JavaScript.

*Observação: a estrutura acima deve ser conferida com a organização final do repositório, mantendo somente os arquivos existentes.*

## 7. Como executar o projeto

O projeto utiliza HTML, CSS e JavaScript, sem necessidade de instalar dependências para abrir a interface.

1. Acesse o repositório do projeto no GitHub.
2. Baixe os arquivos ou clone o repositório utilizando:

```bash
git clone URL_DO_REPOSITORIO
```

3. Abra a pasta do projeto no Visual Studio Code.
4. Localize o arquivo `index.html`.
5. Abra o arquivo no navegador ou utilize a extensão Live Server do Visual Studio Code.
6. Com o Live Server instalado, clique em **Go Live** para visualizar o site.

## 9. Publicação do site com GitHub Pages

Após o desenvolvimento da interface, foi realizada a publicação do projeto utilizando o GitHub Pages, serviço de hospedagem disponibilizado pelo GitHub que permite disponibilizar sites estáticos diretamente a partir de um repositório.

O processo de publicação envolveu as seguintes etapas:

1. Envio dos arquivos HTML, CSS, JavaScript e recursos visuais para o repositório no GitHub.
2. Acesso às configurações do repositório, na opção **Settings**.
3. Abertura da seção **Pages**.
4. Seleção da opção de publicação a partir de uma branch do repositório.
5. Escolha da branch principal e da pasta de origem dos arquivos.
6. Salvamento das configurações e aguardo da publicação.
7. Verificação do endereço gerado para acessar o site pelo navegador.

Com essa configuração, o site passou a ficar disponível publicamente pela internet, permitindo que outras pessoas acessem e naveguem pela interface sem precisar baixar os arquivos do projeto.

**Link do site publicado:** https://emilyms-tech.github.io/Plasso/index.html

O GitHub Pages foi utilizado como solução de hospedagem da versão front-end do projeto.
