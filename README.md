## Sobre o projeto

A **Plasso** é um conceito de estúdio criativo que transforma ideias em
objetos físicos por meio de impressão 3D, gravação a laser e tecnologia
NFC.

Este repositório reúne o desenvolvimento do site institucional da marca.
A experiência foi pensada para apresentar os produtos e projetos do
estúdio, explicar como funciona uma encomenda personalizada e facilitar
o contato de pessoas interessadas em transformar uma ideia em um objeto
real.

O projeto está sendo desenvolvido inicialmente como um protótipo
front-end, com foco em identidade visual, experiência do usuário e
organização do código. Recursos que dependem de servidor, banco de dados
ou autenticação serão implementados em etapas futuras.

## Objetivos

-   Apresentar a identidade e os serviços da Plasso.
-   Exibir produtos e projetos em uma galeria visual.
-   Explicar o processo de criação e encomenda.
-   Permitir que visitantes enviem uma solicitação de orçamento.
-   Evoluir futuramente para uma área administrativa de gerenciamento.

## Identidade visual

A interface busca um equilíbrio entre tecnologia e cuidado artesanal:
acolhedora, contemporânea e suave, sem parecer fria, excessivamente
luxuosa ou rústica.

  Elemento          Definição
  ----------------- -----------
  Bordô             `#6E263B`
  Creme             `#F4EEE5`
  Argila suave      `#C58F78`
  Madeira natural   `#B99A75`
  Marrom profundo   `#43352F`
  Títulos           Fraunces
  Textos            Figtree

A madeira aparece principalmente nas fotografias e em detalhes pontuais.
O bordô é usado como cor de identidade, enquanto o creme mantém a
interface clara e aconchegante.

## Processo de encomenda

A experiência de encomenda foi pensada em cinco etapas:

1.  **Você conta a ideia** --- por uma descrição ou imagem de
    referência.
2.  **Preparamos o orçamento** --- com valores, materiais e prazo.
3.  **Você aprova** --- os detalhes são ajustados até chegar ao
    resultado esperado.
4.  **Fabricamos com cuidado** --- a peça é produzida e conferida.
5.  **Você recebe** --- o objeto pronto para usar ou presentear.

## Como executar

O projeto inicial utiliza HTML, CSS e JavaScript, sem necessidade de
instalar dependências.

1.  Clone este repositório:

    ``` bash
    git clone URL_DO_SEU_REPOSITORIO
    ```

2.  Entre na pasta do projeto:

    ``` bash
    cd plasso
    ```

3.  Abra a pasta no Visual Studio Code.

4.  Execute o arquivo `index.html` no navegador. Para uma experiência
    melhor durante o desenvolvimento, utilize a extensão **Live Server**
    do VS Code e clique em **Go Live**.

> Substitua `URL_DO_SEU_REPOSITORIO` pelo endereço real do repositório
> depois de criá-lo no GitHub.

## Status do projeto

**Em desenvolvimento --- protótipo front-end.**

A primeira etapa é construir a interface pública com base no design da
Plasso. O formulário e outros recursos podem usar comportamento
demonstrativo enquanto não houver backend.

Dados demonstrativos não representam pedidos, clientes ou transações
reais. A autenticação e o gerenciamento administrativo só serão
considerados seguros após a implementação de um backend apropriado.
